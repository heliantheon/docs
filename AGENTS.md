# Heliantheon design docs index

This repository is an index. Do not place project design documents here.

- Store each document under `docs/` in the repository that owns the design.
- Add or update the link in `README.md` when a document moves, is added, or is retired.
- Prefer stable filenames and links to the default branch.
- Keep summaries factual and short; the source document carries the detail.
